# 桌宠模式 · 设计文档

> 核心钩子：**好感度解锁跨端养成**——先在 QQ 里养她，好感度养到 60（"亲近"档），她就能"游到你的桌面上"，变成一个常驻桌宠，退出 QQ 也能继续陪着你。

---

## 一、功能定位

| 阶段 | 好感度 | 你能做什么 |
|------|--------|-----------|
| 阶段 1 · QQ 养成 | 0~59 | 只在 QQ 里聊天、投喂、涨好感度 |
| 阶段 2 · 解锁桌宠 | ≥ 60（亲近） | 她游到桌面，变成悬浮桌宠，退出 QQ 也能聊 |
| 阶段 3 · 挚友 | ≥ 80 | 桌宠解锁更多互动（纪念日、专属对话等，可扩展） |

**这个"解锁"机制是养成的强激励**：用户不会只是"养个 QQ 机器人"，而是"把她养出来、带回家"。

## 二、桌宠形象与技术：直接采用 dsh-pet

我们不自己造桌宠轮子，而是直接集成开源插件 **dsh-pet**：

- **形象**：DeepSeek「大肥鱼 · 鲸鱼娘」——和"深海小鲸"的鲸鱼设定天然契合。
- **能力**：100+ 段透明动画（待机呼吸、打瞌睡、玩魔方、吃火锅、屏幕漫游、点击 Q 弹、拖拽甩抛物理反弹）、AI 对话、记忆持久化、余额展示、系统通知。
- **三种运行形态**：
  1. DSH web 的浏览器悬浮层；
  2. DSH 桌面应用的透明置顶小窗；
  3. **独立模式**：Windows x64 绿色包 `dsh-pet-win-x64.zip`，双击 `dsh-pet.exe` 直接跑，不依赖 DSH 环境。

> 独立模式对"零基础用户"最友好：解压 → 双击 → 填 DeepSeek Key → 桌宠就活了。

## 三、整体架构

```
QQ 端（主养成）               桌面端（桌宠陪伴）
┌─────────────────┐        ┌─────────────────┐
│ NapCat（QQ协议） │        │  dsh-pet 桌宠    │
│ AstrBot（AI框架）│        │  （大肥鱼·鲸鱼娘）│
│ DeepSeek         │        │  DeepSeek        │
│ 好感度插件(SQLite)│        │  记忆本地持久化   │
└─────────────────┘        └─────────────────┘
        共享同一个 DeepSeek Key / 同一个"她"
```

## 四、解锁机制怎么落地（两种做法）

**做法 A（简单，推荐先行）**：概念解锁
- 用户在 QQ 里把好感度养到 60 后，`/状态卡` 里提示"她愿意游到你的桌面了"；
- 用户自己去解压 `dsh-pet-win-x64.zip`，启动桌宠，输入同一个 DeepSeek Key；
- 相当于"把养熟的鱼领回家"，仪式感拉满。

**做法 B（进阶，完全自动）**：数据桥接
- dsh-pet 对外提供 **HTTP 接口**（`/dsh-pet-7340`，本机、无鉴权），别的程序可以驱动它说话、播动画、读状态；
- 写一个轻量桥接脚本：读 AstrBot 的好感度 SQLite → 好感度 ≥ 60 时，调用 dsh-pet 接口"唤醒"桌宠；
- 这样"养到 60 自动解锁桌宠"完全自动化。

> 笔试作品阶段先实现做法 A，做法 B 作为"进阶路线"写进文档即可。

## 五、QQ 端联动：桌宠实时弹对话框（已实现）

**需求**：接入桌宠后，用户在 QQ 里和机器人聊天时，桌宠收到消息会**弹对话框展示自己的回复**——QQ 端和桌宠实时联动。

**实现**：新增「桌宠联动插件」`pet_bridge`，原理：

1. AstrBot 生成回复后，`pet_bridge` 在 `on_llm_response` 钩子里拿到回复文本；
2. 剥掉 `[INTIMACY:±N]` 内部标记（不让气泡露出技术细节）；
3. 通过 dsh-pet 的 HTTP 接口 `POST /dsh-pet-7340/broadcast`，把回复文本写进桌宠气泡；
4. 桌宠弹出气泡，展示这条回复（可联动说话动画）。

**关键接口（2026-11 实机验证）**：

dsh-pet 0.4.x 的 HTTP 服务有两个"隐藏条件"，照文档直接调会失败：

1. **端口是随机的**（不是文档写的 7340 —— 那只是路径前缀）。实际端口记录在 `~/.dsh/dsh-pet/logs.txt` 的「本机服务 http://127.0.0.1:PORT」一行（本次实测为 63267）。
2. **API 需要 token 鉴权**：header `x-dsh-pet-token: <43位token>`（或 Cookie `dsh_pet_token`）。token 每次启动由 `randomBytes(32)` 随机生成、只存在内存，可从 dsh-pet 进程环境变量 `DSH_PET_SITE_URL=http://127.0.0.1:PORT/standalone-ai/#token=xxx` 中提取。

正确调用：

```
POST http://127.0.0.1:<实际端口>/dsh-pet-7340/broadcast?pet=main&surface=desktop
Header: x-dsh-pet-token: <token>
Body:   {"text":"...","duration":9000,"anim":true}
```

注意：`surface` 是 **query 参数**（desktop / web / both / any），放进 body 会报「surface 必填」；桌宠是 desktop 模式时用 `surface=both` 会报 `pet-not-displayed`。

| 接口 | 作用 |
|------|------|
| `POST /dsh-pet-7340/broadcast?pet=main&surface=desktop` | 把外部文本写进桌宠气泡 |
| `POST /dsh-pet-7340/lock?pet=main` | 取占用锁（独占演出，可选） |
| `POST /dsh-pet-7340/bubble/clear?pet=main` | 清除气泡 |

**pet_bridge 的自动化**：自动从 `logs.txt` 读端口、用 ctypes 读 dsh-pet 进程环境变量拿 token（带缓存 + 失败自动重探），所以用户**不需要手动填端口或 token**，dsh-pet 重启换了端口/令牌也能自动跟上。

**降级策略**：桌宠未开启、被占用、接口不可用时，插件静默降级，**绝不影响 QQ 端正常回复**。

> 插件代码见 `01-一键部署工具/电脑版/插件/pet_bridge/main.py`；部署脚本可自动安装它。

**实测结果**：QQ 小号发消息 → DeepSeek 回复 → 桌宠桌面气泡弹出，全链路打通 ✓

## 六、安装 dsh-pet（给用户看的傻瓜步骤）

| 方式 | 步骤 |
|------|------|
| 独立模式（推荐新手） | 下载 `dsh-pet-win-x64.zip` → 解压 → 双击 `dsh-pet.exe` → 填 DeepSeek Key |
| DSH 插件 | 桌面应用「插件管理」填 `dsh-pet`，或命令行 `dsh plugin --profile web add dsh-pet` |
