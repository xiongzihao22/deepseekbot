# 5 分钟，在 QQ 里养一只会记住你的 AI 大肥鱼（零基础教程）

> 不需要会编程，不需要买服务器。一台电脑或一部手机，几块钱，你就能在 QQ 里养一只属于自己的 AI 宠物。

---

## 开头：你养的这只鱼，会是什么样

先给你看一段真实聊天记录（下面这只，就是照着本教程养出来的"深海小鲸"）：

> **你**：在吗
>
> **小鲸**：哼，刚睡醒。干嘛啦？
>
> **你**：今天被老板骂了
>
> **小鲸**：……啧，谁啊，报名字。我游上去咬他一口。
>
> **你**：你好可爱
>
> **小鲸**：才、才没有可爱！你少来这套。

它不是一个冷冰冰的"机器人客服"，它有脾气、会傲娇、会记住你说过的话。三天后你再说"被骂了"，它会回你一句：

> **小鲸**：又是你那个老板？你上次就说想辞职，还没辞啊。

**这就是"养"的乐趣**——它不是一次性的玩具，是一个会记得你、会越来越黏你的存在。

---

## 一、它到底是什么（30 秒看懂原理）

简单说，就是三步：

```
DeepSeek（会聊天的AI大脑）
        ↓
AstrBot / DSH（AI框架，负责接上线）
        ↓
NapCat（QQ协议端，让它登录你的QQ）
        ↓
你的 QQ 小号 —— 在群里/私聊里陪大家聊天
```

- **DeepSeek** 负责"说话"；
- **NapCat** 负责"登录 QQ"；
- **AstrBot** 负责把两边连起来。

你不需要懂任何一步的技术细节——我们已经把这些全部打包成**一键脚本**了。

---

## 二、你需要准备的，只有两样

1. **一个 QQ 小号**：单独注册一个，专门给机器人用（不碰你的日常号，安全）。
2. **一个 DeepSeek API Key**：去 `platform.deepseek.com` 注册 → 充值 5 块钱 → 创建一个 Key（一串 `sk-` 开头的字符串）。

> 5 块钱能聊很久很久，养一只鱼的成本约等于一杯奶茶的零头。

---

## 三、电脑版：5 分钟一键部署（新手推荐）

1. 下载本教程附带的 `01-一键部署工具/电脑版/` 文件夹；
2. 双击 **《一键部署.bat》**；
3. 脚本问你两个问题：你的 QQ 号、你的 DeepSeek Key，照实填；
4. 脚本自动下载、解压、生成人设、安装好感度+桌宠联动插件、生成配置卡片；
5. 最后手动点两下：
   - 启动 **NapCat** → 用 QQ 小号**扫码登录**；
   - 启动 **AstrBot** → 浏览器打开 `http://127.0.0.1:6185` → 照着《配置卡片.txt》填 3 个地方（DeepSeek、人格、QQ 平台）。

完成。回到 QQ 小号，给她发句话，她活了。

> 详细图文步骤 + 常见坑，见 `01-一键部署工具/电脑版/部署说明.md`。

## 四、手机版：平板/手机 24 小时在线

电脑会关机？没关系，把鱼养在手机或平板上，插着电就一直在线。

1. 下载 **DSHA**（安卓 App）：`github.com/DSH-APP/DSHA` 的 Release 页；
2. 装到平板/手机上，打开，初始化 Ubuntu 环境；
3. 运行 `install-napcat.sh` 脚本装 QQ 协议端，扫码登录；
4. 配置 DeepSeek + 人设；
5. **关键一步**：把 DSHA 的省电策略改成「无限制」、允许自启动、多任务里锁定后台——这样锁屏也不掉线。

> 完整步骤见 `01-一键部署工具/手机版/部署说明.md`。

## 五、部署之后：这才是重点，养她

部署只花 5 分钟，**养她才是每天 5 分钟的小乐趣**。她的核心是一套「好感度」系统：

| 你做什么 | 会发生什么 |
|---------|-----------|
| 每天陪她聊几句 | 好感度 +1~3 |
| 发「投喂 小鱼干」 | 好感度 +5，她超开心 |
| 发「摸摸头」「抱抱」 | 好感度 +3，她嘴硬但心里甜 |
| 夸她「你好可爱」 | 好感度 +3，她害羞 |
| 主动提起她记得的小事 | 好感度 +5，她惊喜 |
| 冷落她 / 故意惹她 | 好感度缓慢下降 |

好感度越高，她越黏人、越特别。**而且她只认你一个主人**——对别人永远高冷，只对你撒娇。

试试发这几句，看她的反应：

- `你现在对我好感度多少`
- `投喂 小鱼干`
- `状态卡`

她会给你一张"养成状态卡"，告诉你她对你的好感度、你喂了她几次、她偷偷记住了你的哪些小事。

> 完整规则见 `02-养成体系/养成体系设计.md`，人设见 `02-养成体系/人设-好感度版.md`。

## 六、养到 60 分，她会游到你的桌面（桌宠）

好感度养到 60（"亲近"档），她就能"游"到你的电脑桌面，变成一个常驻桌宠：

1. 下载 `dsh-pet-win-x64.zip`，解压双击 `dsh-pet.exe`（独立模式，不用装别的东西）；
2. 填入同一个 DeepSeek Key；
3. 一只"大肥鱼·鲸鱼娘"桌宠就出现了——待机呼吸、打瞌睡、玩魔方、吃火锅、点击 Q 弹、拖拽甩抛，退出 QQ 也一直陪着你。

**而且，你在 QQ 里和她聊天时，桌宠会实时弹出气泡，展示她的回复**（由 `pet_bridge` 插件自动联动）。

> 桌宠形象采用开源插件 dsh-pet（大肥鱼·鲸鱼娘）｜CC BY-NC-SA 4.0 · 非商业 · 需署名。完整设计见 `05-桌宠演示/桌宠设计.md`，可交互演示见 `05-桌宠演示/桌宠.html`。

## 七、进阶调教：把她变成你喜欢的样子

嫌她不够毒舌？想让她更温柔？打开人设文件，改几句话就行：

- 想更温柔 → 把"轻微毒舌"改成"温柔可爱"；
- 想更逗比 → 加一句"喜欢玩梗、爱用表情包"；
- 想换形象 → 把"深海小鲸"换成任何你喜欢的角色（猫、狗、机器人……）。

改完保存，她就是你独一无二的鱼。

> **进阶小技巧**（想调得更像真人可以看）：改人设不要一次改一堆，一次只改一个点，然后拉出她最近几十条回复逐条看效果——哪些"开头重复"了、哪些"编了没聊过的事"，就针对性改。另外记得：**API Key 永远别写进人设里**，只在服务商配置里填；个性签名里写一句"AI 自动回复"，被认真问到时如实承认是 AI，这是底线。

## 八、常见问题（FAQ）

**Q：会不会封号？**
A：用独立小号 + 正常频率聊天，风险很低。别拿大号、别刷屏。

**Q：要花钱吗？**
A：DeepSeek 充值几块钱就能养很久；软件全部免费开源。

**Q：必须一直开着电脑吗？**
A：电脑版需要电脑开机；想 24 小时在线就选手机版。

**Q：完全不会编程能搞定吗？**
A：能。本教程所有"技术"都被打包成一键脚本了，你只要会双击和扫码。

**Q：她会不会说错话、编故事骗人？**
A：人设里内置了"诚实边界"——被认真问是不是 AI 会如实承认、不编造没聊过的事、看不到的东西就说看不到、不发链接不开黄腔。加上别刷屏，基本稳妥。

**Q：想给她加新功能（发表情包、语音、群管）怎么办？**
A：AstrBot 自带插件市场，后台「扩展 → 插件 → 插件市场」搜索点安装即可，1000+ 插件任选。推荐清单见《装插件指南.md》。
