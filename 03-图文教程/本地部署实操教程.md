# 本地部署实操教程（Windows）

> 这份是**给自己照着做**的手册：从一台干净电脑，到她在 QQ 里回你话、再游到你桌面上。
> 面向「想真的跑起来」的人，包含每一步的**验证方法**和**排错表**。
> 想看传播向的轻量版本 → [`公众号版-从0养一只AI小鲸鱼.md`](公众号版-从0养一只AI小鲸鱼.md)

---

## 零、开工前先确认三件事

| 项 | 要求 | 为什么 |
|---|---|---|
| 系统 | Windows 10 / 11（64 位） | NapCat 只有 Windows 一键版 |
| 安装路径 | **纯英文，不含中文和空格** | 路径含中文会让 NapCat 启动器拼路径截断，报 `Error Code: 2` |
| 网络 | 能访问 GitHub 和 DeepSeek | 首次部署要下载约 200MB 组件 |

> 推荐的最终路径：`D:\deepseekbot`（就放在根目录下一层，最省事）

---

## 一、准备两样东西

### 1. QQ 小号

- 单独注册一个，**不要用日常号**（协议端登录有风险，小号更安全）
- 记下它的 QQ 号，部署时要填
- 小号要能正常登录手机 QQ（要扫码）

### 2. DeepSeek API Key

1. 打开 <https://platform.deepseek.com> 注册
2. 左侧「API keys」→ 创建
3. 复制 `sk-` 开头的字符串（**只显示一次，先存下来**）

> 费用参考：日常聊天一天几毛钱。充 10 块能用很久。

## 二、部署（三种方式，选一种）

### 方式 A：一键脚本（推荐）

```
双击  01-一键部署工具\电脑版\一键部署.bat
```

脚本会依次问你要 **QQ 号** 和 **DeepSeek Key**，然后自动完成：

```
[1/6] 下载 NapCat（约 1MB）+ AstrBot（约 180MB）
[2/6] 解压
[3/6] 首次启动 AstrBot 生成数据目录
[4/6] 安装插件 intimacy + pet_bridge
[5/6] 写入 DeepSeek / QQ 平台 / 人设 三项配置
[6/6] 写好 NapCat 反向 WS 配置
```

**跑完之后你还需要做一件事**：启动 NapCat 扫码（见下一节）。

### 方式 B：领养向导（最有仪式感）

```
双击  06-领养UI\启动领养向导.bat
```

浏览器自动打开 → 点中间的**领养蛋** → 填 Key 和 QQ 号 → 看孵化进度 → 网页里直接显示二维码 → 扫码。

全程不碰黑窗口。适合第一次装、想看清每一步在干嘛。

### 方式 C：手动部署（想搞懂原理的看这段）

```powershell
# 1. 建目录（务必纯英文）
mkdir D:\deepseekbot

# 2. 下载两个组件
#    NapCat OneKey:  https://github.com/NapNeko/NapCatQQ/releases  → NapCat.Shell.Windows.OneKey.zip
#    AstrBot 便携版: https://github.com/AstrBotDevs/AstrBot-desktop/releases → windows_amd64_portable.zip

# 3. 分别解压到 D:\deepseekbot\napcat 和 D:\deepseekbot\astrbot

# 4. 首次运行 NapCat 安装器（会下载内置 QQ 9.9.33，约 300MB）
#    双击 napcat\NapCatInstaller.exe，等它装完

# 5. 装插件：把 01-一键部署工具\电脑版\插件\ 下的两个目录
#    复制到 C:\Users\<你的用户名>\.astrbot\data\plugins\

# 6. 跑配置脚本（把 QQ 号和 Key 换成你自己的）
cd D:\deepseekbot\astrbot\AstrBot_*\backend
python launch_backend.py          # 先跑一次生成数据目录，然后 Ctrl+C
cd D:\deepseekbot\01-一键部署工具\电脑版
python setup_config.py "sk-你的Key" "你的QQ号" "D:\deepseekbot"
```

## 三、启动顺序（这一步最容易错）

**必须是这个顺序**，顺序错了连不上：

```
① 启动 NapCat    →  ② 扫码登录 QQ  →  ③ 启动 AstrBot（自动带起桌宠守护）
```

### ① 启动 NapCat

```
双击  01-一键部署工具\电脑版\启动NapCat.bat
```

它会做一件关键的事：**带上 hook 参数启动 QQ**

```
NapCatWinBootMain.exe  "…\QQ.exe"  "…\NapCatWinBootHook.dll"
```

> ⚠️ 少传这两个参数，QQ 能跑、网络也通，但 NapCat 永远「未接管」——表现就是**二维码永远刷不出来**。

**成功的标志**（看那个黑窗口）：

```
网络已连接
快速登录失败，未找到历史记录，将尝试密码回退登录
请扫描下面的二维码
二维码已保存到 …\cache\qrcode.png
```

### ② 扫码

用**手机 QQ 小号**扫二维码（黑窗口里那个，或网页里的）。

看见「登录成功」再往下走。

### ③ 启动 AstrBot

```
双击  01-一键部署工具\电脑版\启动AstrBot.bat
```

它会做两件事：

1. 先拉起**桌宠守护进程**（最小化的「桌宠守护」窗口，别关它）
2. 再启动 AstrBot

等约 20 秒，浏览器打开 <http://localhost:6185> 能看到界面就说明好了。

## 四、逐项验证（5 个检查点）

跑完别急着聊，按这个顺序确认，出问题能立刻定位。

### 检查点 1：AstrBot 后端活着

浏览器打开 `http://localhost:6185`，能看到登录/主界面 → ✅

### 检查点 2：插件加载成功

看 AstrBot 的启动日志（或 `C:\Users\<你>\.astrbot\logs\backend.log`），应该有：

```
Plugin intimacy (1.0.0) by deepseekbot: 好感度养成系统…
Plugin pet_bridge (1.0.0) by deepseekbot: 桌宠联动…
```

### 检查点 3：QQ 和 AstrBot 真的连上了

命令行执行：

```bash
netstat -ano | findstr :6199
```

要看到 **`ESTABLISHED`**，不能只有 `LISTENING`。

```
TCP  127.0.0.1:6199  127.0.0.1:xxxxx  ESTABLISHED   ← 这才是通了
```

### 检查点 4：她会回话

在 QQ 里给小号发一句「你好」。

能收到回复 → ✅ 整条链路通了。

### 检查点 5：好感度在工作

```
/好感度      →  （小声）我对你的好感度是 0 / 100
投喂小鱼干    →  好感度变 5
/状态卡      →  状态卡片，含数值 / 投喂次数 / 桌宠状态
```

## 五、日常使用

### 关于好感度

| 你的动作 | 好感度 |
|---|---|
| 聊得开心 | +3 |
| 投喂小鱼干 | **+5** |
| 摸摸头 / 被夸 | +3 |
| 主动提起她记得的小事 | +5 |
| 一天不理她 | −1 / 天 |

档位：`0~19` 陌生 → `20~39` 认识 → `40~59` 熟悉 → `60~79` 亲近 → `80~100` 挚友

### 关于桌宠

- **好感度到 60**，她会主动问「想不想让我去你身边」，回「愿意」→ 桌宠自动出现
- 之后想再叫她出来，发 `/桌宠`
- 桌宠可以拖动、会打瞌睡、会玩魔方
- 关掉 QQ 后，在桌面上双击她也能聊天

### 每次开机怎么启动

只做一件事：

```
双击  启动AstrBot.bat
```

> NapCat 也要在跑。如果 NapCat 没开，QQ 那边就没反应——两个都要启动。

## 六、排错表（按现象查）

| 现象 | 原因 | 解决 |
|---|---|---|
| `Error Code: 2`，路径在中文处截断 | 安装路径含中文 | 整个文件夹移到纯英文路径（如 `D:\deepseekbot`），重新启动 |
| NapCat 起来了，但二维码一直不出现 | 启动器没传 hook 参数 | 必须用 `napcat.bat` / `启动NapCat.bat` 启动，别直接双击 `NapCatWinBootMain.exe` |
| `.bat` 双击报 `'ho. 不是内部或外部命令` + 乱码 | 文件被存成了 LF 换行 / UTF-8 | 用仓库里的原始文件，别用编辑器另存；需要修复见 README「踩坑 5」 |
| QQ 能发消息但机器人不回 | 反向 WS 没连上 | 查 `netstat -ano \| findstr :6199` 是否有 `ESTABLISHED`；没有就检查 NapCat 配置里的 `network.websocketClients` |
| 日志报 `'Context' object has no attribute 'db'` | 插件用了旧版 API | 更新到仓库最新版插件（已改用 `get_kv_data`） |
| `/好感度` 报插件异常 | 插件缺 `metadata.yaml` 或没加载 | 检查 `~/.astrbot/data/plugins/intimacy/` 里是否有 `metadata.yaml` |
| 桌宠说"门卡住了" | 守护进程没在跑 | 双击 `启动桌宠守护.bat`，或重开 `启动AstrBot.bat` |
| 桌宠有进程但桌面看不见 | 启动环境缺桌面会话 | 确保是双击 bat 启动，别用服务/后台方式 |
| 部署脚本下载失败（TLS 证书错） | 本机代理或证书问题 | 用 `curl -k` 或 PowerShell 重下；脚本里已内置重试 |

## 七、端口速查

| 端口 | 是谁 | 用来干嘛 |
|---|---|---|
| `6099` | NapCat WebUI | 看登录状态、改网络配置 |
| `6199` | AstrBot OneBot | NapCat 反向 WS 连这里 |
| `6185` | AstrBot WebUI | 改配置、装插件 |
| `5199` | 领养向导（Flask） | 网页领养界面 |
| `5288` | 桌宠守护进程 | 插件通过它拉起桌宠 |

## 八、想重来一遍怎么办

```bash
# 只重置她（记忆和好感度清零，其他都保留）
删除  C:\Users\<你>\.astrbot\data\data_v4.db

# 完全重装
删除  C:\Users\<你>\.astrbot        （AstrBot 的配置和记忆）
删除  D:\deepseekbot\napcat         （含内置 QQ 和登录状态）
删除  D:\deepseekbot\pet\dsh-pet\   （桌宠配置在 C:\Users\<你>\.dsh）
```

> 删 `~/.dsh` 会清掉桌宠的所有设置（包括她的名字），慎重。
