## 这是什么

一个把「QQ 聊天机器人」产品化成**养成游戏**的项目。

它不是又一个「接入大模型的群机器人」，而是：

- **把你和她的关系做成数值**——好感度 0~100，随聊天/投喂/抚摸实时变化，存进数据库，重启不丢；
- **让她有真正的性格**——傲娇、轻怼、会嘴硬，但有清晰的诚实边界，不编造、不装人；
- **让她从屏幕里走出来**——好感度到 60 解锁桌宠，退出 QQ 也能看见她、和她说话；
- **让零基础的人也能拥有她**——部署全自动化，用户只需要「填 Key + 扫码」。

### 三个核心体验

| 阶段 | 在哪玩 | 玩什么 |
|------|--------|--------|
| ① 在 QQ 里养 | QQ 群/私聊 | 聊天涨好感、投喂小鱼干、摸摸头、看状态卡 |
| ② 她问你要不要去你身边 | QQ | 好感度首次达到 60，她主动开口问 |
| ③ 桌面陪伴 | 桌面 | 桌宠常驻，QQ 里的每句回复实时弹成对话气泡 |

## 快速开始（Windows 电脑版）

### 你需要准备两样东西

1. **一个 QQ 小号**（建议单独注册，别用日常号）
2. **一个 DeepSeek API Key**（[platform.deepseek.com](https://platform.deepseek.com) 申请，几块钱能用很久）

### 然后只需要 2 步

```text
① 双击  01-一键部署工具/电脑版/一键部署.bat
② 填    你的 QQ 号 + DeepSeek Key，然后扫码登录 QQ 小号
```

脚本会自动完成剩下的一切：

```
下载 NapCat（约 1MB）+ AstrBot（约 180MB）
  → 解压到项目根目录的 napcat/ 和 astrbot/
  → 引导你运行 NapCat 安装器（首次会下载内置 QQ，约 300MB）
  → 首次启动 AstrBot（会下载 WebUI，约 1 分钟）
  → 安装 2 个自研插件（好感度养成 + 桌宠联动）
  → 写入 DeepSeek 服务商 + QQ 平台连接
  → 写入人设（含你的 QQ 号）
  → 配置 NapCat 反向 WebSocket
  → 完成
```

> **耗时说明**：整个过程主要花在下载上（组件 + 内置 QQ 约 480MB），
> 取决于网速，通常 **10~20 分钟**。部署只需做一次。

> 之后每次开电脑，只需双击 `启动AstrBot.bat`（它会同时带起桌宠守护进程）。
> 另需先双击 `启动NapCat.bat` 扫码登录。

### 想更傻瓜：用领养向导

```text
双击  06-领养UI/启动领养向导.bat
  → 浏览器自动打开深海界面
  → 点「领养蛋」→ 填 Key + QQ 号 → 看孵化进度 → 扫码
```

全程在网页里点，不碰任何黑窗口。

### 关键设计：为什么需要「桌宠守护进程」

这是整个项目踩得最深的坑，也是最有价值的一处设计。

**问题**：dsh-pet 是 Electron 应用。如果由 AstrBot 的 Python 进程直接 `Popen` 拉起，会出现「**有进程、无窗口、不写日志**」的诡异状态——QQ 端一切正常，桌面上却什么都没有。

实测三种方式：

| 启动方式 | 结果 |
|---------|------|
| AstrBot 进程直接 `Popen` | ❌ 连进程都起不来 |
| AstrBot 进程经 `cmd /c start` | ❌ 起了 2 个进程，但无窗口 |
| **独立守护进程启动** | ✅ 窗口正常出现 |

**原因**：GUI 进程需要可用的桌面会话句柄，AstrBot 的进程环境给不了。

**解法**：`pet_launcher.py` 是一个独立的小服务（监听 `127.0.0.1:5288`），由桌面双击启动，具备完整桌面会话。插件只需 `POST /launch`，它负责把桌宠拉起来，并轮询检测窗口是否真的出现。

```python
# 插件侧：优先请守护进程帮忙，失败才回退本地启动
if await asyncio.to_thread(self._launch_via_daemon):
    return True, ""
```

## 好感度系统

初始值 **0**——部署后她对任何人都是一片空白、态度生疏、没有记忆。
不同的人部署，养出来的就是**不同的她**（每个实例有独立的 SQLite 数据库）。

### 增减规则

| 事件 | 变化 | 判定方式 |
|------|------|---------|
| 普通聊天（敷衍/短句） | +1 | 语义 |
| 普通聊天（聊得开心/接梗） | +3 | 语义 |
| 投喂 `投喂小鱼干` | **+5** | 关键词 |
| 抚摸 `摸摸头` / `抱抱` | +3 | 关键词 |
| 被夸 | +3 | 语义 |
| 主动提起她记得的小事 | +5 | 语义 |
| 冷落 | −1 / 天 | 定时衰减 |
| 故意惹她 | −3 | 语义 |

### 档位

| 好感度 | 关系 | 表现 |
|--------|------|------|
| 0~19 | 陌生人 | 礼貌但冷淡，话少 |
| 20~39 | 认识 | 开始记得你，但嘴硬不承认 |
| 40~59 | 熟悉 | 轻怼、接梗，笨拙地安慰你 |
| 60~79 | 亲近 | **解锁桌宠**、主动、黏人 |
| 80~100 | 挚友 | 只对你特别，护短、吃醋 |

> 非主人好感度**永远锁在 39 以下**，绝不叫任何人「主人」。

### 结构化存储（不是让 AI 自己记）

模型每次回复末尾会输出一个内部标记，插件解析后写入数据库并**剥掉标记**，用户看到的是干净回复：

```
模型输出：……哼，谁要理你。[INTIMACY:+5:feed]
用户看到：……哼，谁要理你。
数据库：  intimacy(100000000).intimacy = 14 → 19
```

好处：数值稳定不漂移、可直接查询、重启不丢、支持 `/状态卡` 精确展示。

### 指令集

| 指令 | 作用 |
|------|------|
| `/好感度` | 查当前数值（嘴硬看心情报不报） |
| `/状态卡` | 养成状态卡（数值 / 投喂次数 / 桌宠状态） |
| `/桌宠` | 让她来到桌面 / 查询解锁进度 |
| `/设置好感度 59` | 调试用，仅主人可用（演示解锁流程很方便） |

## 桌宠联动

好感度到 60，她会主动问：

> （她忽然安静下来，声音很轻）那个……我好像，可以离开深海了。你……想让我去你身边吗？

你说「愿意」→ 桌宠自动出现。

之后你在 QQ 里说的每句话，她的回复都会**实时弹到桌面气泡**：

```
QQ 收到消息 → AstrBot 生成回复 → pet_bridge 插件
  → 剥掉好感度标记 → 自动发现 dsh-pet 端口与 token
  → POST /dsh-pet-7340/broadcast → 桌宠弹出气泡
```

> `pet_bridge` 会自动从 dsh-pet 的日志里读端口、从进程环境里取 token，**不需要手动配置**。

## 踩过的坑（都已修复并固化进代码）

| # | 坑 | 现象 | 修复 |
|---|----|------|------|
| 1 | NapCat 启动器无参数 | `Error Code: 2`、二维码刷不出、Worker 崩溃 | 必须传 `QQ.exe` + `NapCatWinBootHook.dll` 两个参数 |
| 2 | 路径含中文 | 启动器拼路径被截断 | 全部改用纯英文路径 |
| 3 | NapCat 4.18+ 配置改嵌套 | QQ 连不上 AstrBot，消息发不出 | 配置改为 `network.websocketClients` |
| 4 | 插件缺 `metadata.yaml` | 插件加载失败 | 补齐必需字段 + 移除废弃的 `@register` |
| 5 | `.bat` 用 LF 换行 | `'ho. 不是内部或外部命令` + 乱码 | 统一 CRLF + GBK + `chcp 936` |
| 6 | AstrBot 4.29 移除 `context.db` | `'Context' object has no attribute 'db'` | 改用插件基类的 `get_kv_data/put_kv_data` |
| 7 | `ELECTRON_RUN_AS_NODE=1` | Electron 以纯 Node 模式跑，无窗口 | 启动前清理该环境变量 |
| 8 | GUI 子进程无桌面会话 | 有进程、无窗口 | 独立守护进程 + HTTP 触发 |

## 常见问题

**Q：完全不会编程能搞定吗？**
能。技术部分全在一键脚本里，你只要会双击和扫码。

**Q：她会说错话、编故事吗？**
人设里内置了诚实边界：被认真问是不是 AI 会承认、不编造没聊过的事、看不到的就说看不到、不发链接、不接黄腔、不聊政治。

**Q：我的聊天记录会上传到哪？**
只在你本机的 `~/.astrbot/data/data_v4.db` 里，除了 DeepSeek 的 API 请求本身，不会外传。

**Q：手机能跑吗？**
可以，见 [`01-一键部署工具/手机版`](01-一键部署工具/手机版/)，用 Android + Ubuntu 容器方案做到 7×24 在线（电脑关机也不掉线）。

**Q：桌宠没出现怎么办？**
先确认 `启动AstrBot.bat` 启动时那个「桌宠守护」小窗口还在（它负责拉起桌宠）。详见 [`05-桌宠演示/桌宠设计.md`](05-桌宠演示/桌宠设计.md)。
