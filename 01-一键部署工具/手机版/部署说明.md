# 手机版 · 部署说明（平板 / 手机 7×24 在线）

> 适合：电脑会关机、想随时随地让机器人不掉线的人。
> 原理：用 **DSHA**（一个把 Ubuntu 环境封装成 App 的安卓启动器）在手机/平板上跑 QQ 协议端 + AI 框架，
> 配合看门狗和前台服务，做到**锁屏、息屏也不掉线**。

---

## 一、为什么用手机版

| 电脑版 | 手机版 |
|--------|--------|
| 电脑开机才在线 | 手机/平板插电就 24 小时在线 |
| 部署快（约 5 分钟） | 部署稍慢（约 15 分钟），但一劳永逸 |
| 适合新手体验 | 适合长期养 |

## 二、开始前准备

| 准备项 | 说明 |
|--------|------|
| 一台安卓设备 | 平板/手机均可，建议用闲置设备或小米平板 6S Pro 这类 |
| QQ 小号 | 同电脑版 |
| DeepSeek API Key | 同电脑版 |

## 三、部署步骤（傻瓜式）

### 第 1 步：下载并安装 DSHA

1. 打开 GitHub 项目页：**https://github.com/DSH-APP/DSHA**
2. 下载最新 Release 的 APK（arm64 版本）；
3. 传到平板/手机上，点击安装（允许"未知来源"安装）。

> 校验：下载后可用 SHA256 校验是否完整（校验值见 Release 页）。

### 第 2 步：启动 DSHA 环境

1. 打开 DSHA App，首次会初始化一个 Ubuntu 24.04（arm64）环境；
2. 等待初始化完成，进入终端界面。

### 第 3 步：安装 QQ 协议端（NapCat）

把随包提供的 `install-napcat.sh` 脚本上传到设备，或用终端执行：

```bash
bash install-napcat.sh
```

脚本会自动完成：下载 NapCat → 解压 → 配置 OneBot WebSocket（`ws://127.0.0.1:6199/ws`，Array 格式）→ 启动。

### 第 4 步：安装 AI 框架（DSH / AstrBot）

- 若用 DSH：安装 `dsh-qq-bridge` 插件（HTTP 服务，端口 3000）连接 QQ；
- 若用 AstrBot：与电脑版相同，配置 DeepSeek 服务商 + 人格 + OneBot 平台。

### 第 5 步：扫码登录 + 配置

1. NapCat 启动后弹出二维码，用 **QQ 小号**扫码登录；
2. 在框架后台填 DeepSeek Key + 人设（直接复用电脑版生成的《人设-自动生成.md》）；
3. 给机器人发句话测试。

## 四、关键：让它在后台一直活着

手机/平板默认会"杀后台"，必须做以下设置（以小米 HyperOS 为例，其他系统类似）：

1. **省电策略**：设置 → 应用 → DSHA → 省电策略 → 选「无限制」；
2. **自启动**：设置 → 应用 → DSHA → 允许自启动；
3. **锁定后台**：在多任务界面，把 DSHA 卡片下拉锁定；
4. **（进阶）** 若系统仍杀进程，用 adb 关闭对幽灵进程的限制：
   ```
   adb shell settings put global hidden_api_policy 1
   ```
   并配合 DSHA 自带的**看门狗 + 前台服务**（前台常驻通知），基本能稳定在线。

## 五、验收清单（部署完务必测一次）

- [ ] 锁屏 30 分钟后，用另一个号发消息，机器人仍能秒回；
- [ ] 重启平板后，DSHA 能自动拉起（或手动重开一次能恢复）；
- [ ] 连续挂机一天不掉线。

## 六、常见问题

| 现象 | 解决 |
|------|------|
| 锁屏后掉线 | 省电策略改「无限制」+ 锁定后台 + 前台服务 |
| 重启后不再运行 | 开启自启动，或开机手动打开一次 App |
| 登录失效 | 偶尔需重新扫码，属正常，重登即可 |
