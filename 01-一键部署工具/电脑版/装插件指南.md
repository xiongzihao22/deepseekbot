# 装插件指南：怎么给你的鲸鱼加新功能

> 养鱼想加新功能（发表情包、被戳有反应、语音、群管……）全靠插件。
> 好消息：**AstrBot 自带插件市场，1000+ 插件，搜索点一下就装好，根本不用手动下载。**

---

## 一、最简单的方式：WebUI 插件市场（推荐，零下载）

1. 打开 AstrBot 后台 `http://127.0.0.1:6185`；
2. 左侧点 **扩展（Extensions）** → **插件（Plugins）** → 顶部切到 **插件市场（AstrBot Plugin Market）**；
3. 在搜索框输入关键词（比如"表情包""语音""戳一戳"）；
4. 点进插件详情，看下简介和 AstrBot 版本要求，点 **安装（Install）**；
5. 回到 **已安装（Installed）**，确认它正常加载（没有报错）；
6. 有些插件需要点卡片上的**齿轮图标**做配置（比如填 API Key、设概率），按作者说明填即可。

> 装完发 `/help` 能看当前可用的命令，或到「扩展 → Handlers → Command」里管理。

## 二、养鱼推荐插件清单

| 插件 | 作用 | 在插件市场搜什么 |
|------|------|-----------------|
| 表情包管理器（meme_manager） | 让鲸鱼会发表情包、控制频率 | `表情包` 或 `meme` |
| 专业戳一戳 | 别人戳她时有随机反应（跟戳/反戳/表情包） | `戳一戳` |
| 可自定义好感度系统 | 市场上现成的好感度插件（见下方说明） | `好感度` |
| QQ 群管 | 禁言、踢人、改头衔、设精华等群管理 | `群管` 或 `群管理` |
| QQ 资料卡片（盒） | 查某人的 QQ 资料图 | `资料卡` 或 `盒` |
| 语音 TTS | 让她发语音（需配置语音服务） | `tts` 或 `语音` |

> 提示：插件市场里有个「**可自定义好感度系统**」插件，和我们预装的 `intimacy` 插件功能类似。**二选一即可**——建议就用我们预装的那个（更贴合深海小鲸人设、初始生疏的设定），除非你想玩更复杂的人际关系系统。

## 三、手动安装（兜底，一般用不到）

如果插件市场里搜不到某个 GitHub 上的插件：

1. 到 GitHub 下载插件文件夹（通常以 `astrbot_plugin_` 开头，内含 `main.py`）；
2. 放进 AstrBot 的 `data/plugins/` 目录；
3. 或直接在插件页面右下角点 **安装插件（+）**，用 URL 或上传文件安装。

## 四、我们预装的插件

一键部署脚本已经自动装好了 **好感度插件（intimacy）**，无需你再动手：

- `/好感度` —— 查结构化好感度数值；
- `/状态卡` —— 生成养成状态卡。

## 五、装插件的注意事项

1. **看清楚版本要求**：有些插件要求特定 AstrBot 版本，装不上就看报错提示；
2. **别装太多**：插件越多越重、越容易冲突，按需装；
3. **插件来源要甄别**：插件市场的插件由社区维护，官方不保证绝对安全，装前看下下载量和更新时间；
4. **装完重启或重载**：加载失败的插件会在「加载失败插件」列表里，修复后点「重载」即可。
