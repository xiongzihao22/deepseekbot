# 电脑版 · 部署说明（Windows）

> 面向零基础。跟着做即可，全程不需要会编程。
> 本说明是《一键部署.bat》的图文补充，脚本能自动完成的部分已标注，剩下的"扫码登录、填参数"照着图走就行。

---

## 一、开始前，准备两样东西

| 准备项 | 说明 | 获取方式 |
|--------|------|---------|
| QQ 小号 | 建议单独注册一个，专门给机器人用，不影响你的日常号 | 直接注册 |
| DeepSeek API Key | 一串 `sk-` 开头的密钥，几块钱能用很久 | 官网 `platform.deepseek.com` → 充值几块 → 创建 API Key |

> 为什么用"小号"：机器人本质是一个登录了 QQ 的账号在替你聊天，用独立号最安全、不怕封号影响日常。

## 二、一键脚本会自动做什么

双击《一键部署.bat》后，它会：

1. 问你**主人 QQ 号**和 **DeepSeek Key**（只问一次）；
2. 创建目录、**下载** NapCat（QQ 协议端）和 AstrBot（AI 框架）；
3. **解压**到对应文件夹；
4. **自动配置一切**：首次启动 AstrBot 初始化 → 自动安装好感度+桌宠插件 → 自动写入 DeepSeek 服务商、QQ 平台、人设（`setup_config.py` + `configure.py` 完成）；
5. 完成后，你只需扫码登录 QQ 小号，就能开始养了。

> 部署后，在 QQ 里发 `/好感度`、`/状态卡`，就能查结构化存储的好感度数值（真实存在数据库里，重启不丢）。

## 三、如果自动下载失败（手动兜底）

脚本里的下载地址若因网络/代理/版本更新失效，就手动下载，解压后放到对应文件夹：

| 组件 | 作用 | 官方下载地址 |
|------|------|-------------|
| NapCat OneKey 一键版 | QQ 协议端（内置独立 QQ，免装你本机 QQ） | https://github.com/NapNeko/NapCatQQ/releases |
| AstrBot | AI 框架（负责接 DeepSeek 和 QQ） | https://github.com/AstrBotDevs/AstrBot/releases |

- NapCat 选 **OneKey/一键版**（Windows），解压后放进 `NapCat\`；
- AstrBot 选 Windows 版压缩包，解压后放进 `AstrBot\`。

## 四、部署完成后，你只需两步

配置已全部自动完成，你只需要：

1. 双击 **《启动NapCat.bat》** → 用 QQ 小号**扫码登录**；
2. 双击 **《启动AstrBot.bat》** → 浏览器打开 `http://127.0.0.1:6185`（账号 `astrbot`，密码见启动窗口里打印的随机密码，首次登录后可改）。

然后回到 QQ 小号，发一句 `/好感度`，她活了。

> 注意：NapCat 首次登录后，需在 NapCat WebUI（`http://127.0.0.1:6099`）的「网络配置」里，新增一条**反向 WebSocket**，指向 `ws://127.0.0.1:6199/ws`——AstrBot 已在 6199 端口监听等待 NapCat 连入。

## 五、新手常见坑（我们替你踩过）

| 现象 | 原因 | 解决 |
|------|------|------|
| 下载一直失败 / 报 TLS 证书错 | 本机代理或 GitHub 连接问题 | 用浏览器手动下载，或关掉代理再试 |
| 解压后文件数量不对（少几千个） | Windows 长路径限制 | 用 7-Zip 解压，或把压缩包放到盘符根目录再解 |
| 启动后页面 401/502 假错误 | 系统 http_proxy 代理劫持 | 启动命令加 `--noproxy` 或关掉系统代理 |
| 改了配置不生效 | 旧进程占着端口持旧配置 | 任务管理器结束旧的 python/AstrBot 进程后重启 |
| 登录失败 | QQ 版本与 NapCat 不匹配 | 用 NapCat OneKey 内置的独立版 QQ，别用你自己装的 QQ |
| 启动 NapCat 报 `Error Code: 2` | 路径含中文或空格 | NapCat 官方要求**纯英文路径**，整个安装路径不能有中文（含父目录） |
| QQ 能扫码登录，但机器人不回消息 | 反向 WS 配置格式过旧（NapCat 4.18+ 改了结构） | 配置必须是 `{"network":{"websocketClients":[...]}}` **嵌套**格式，扁平写法会被忽略 |
| NapCat 启动后二维码一直转圈/生成不出来、`coreReady=false` | 启动器没传 Hook 参数，hook DLL 没注入 | 必须用 `NapCatWinBootMain.exe QQ.exe NapCatWinBootHook.dll` 启动（见下） |
| 双击 bat 一闪而过 / 报 `'ho.' 不是内部命令` | bat 用了 LF 换行 | 用 **CRLF + GBK** 编码保存 |

### NapCat 正确启动方式（重要）

不要直接双击 `napcat.bat`（它是无参数调用，hook 不会注入，QQ 会变成"裸 QQ"，NapCat 接管不了登录模块，表现为二维码永远生成不出来）。

正确做法是在 `NapCat.XXXX.Shell` 目录下执行：

```bat
NapCatWinBootMain.exe QQ.exe NapCatWinBootHook.dll
```

本项目已把 `启动NapCat.bat` 改成这个正确形式。启动成功的日志特征是：

```
Boot Command: "...\QQ.exe" --enable-logging -q QQ.exe
网络已连接
请扫描下面的二维码...
二维码已保存到 ...\cache\qrcode.png
```

## 六、安全与合规清单（务必照做）

| 事项 | 为什么 | 怎么做 |
|------|--------|--------|
| API Key 不进提示词 | 防止被套话泄露 | Key 只填在服务商配置里，永远不要写进人设/系统提示词 |
| 加免责声明 | 避免被当成官方/真人 | 在 QQ 个性签名/人设里写明"AI 自动回复""非官方同人角色" |
| 承认 AI 身份 | 诚实是底线 | 人设里已内置：被认真问到时承认是 AI，不装真人 |
| 监控掉线 | 程序"静默失败"最可怕 | 定期看一眼它有没有正常回消息；长期挂机建议装个心跳告警 |
| 频率克制 | 防封号 | 别刷屏、别批量 @，被拦截就暂停 |
